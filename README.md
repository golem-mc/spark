# spark for golem

An unofficial port of [spark](https://spark.lucko.me/), the performance profiler, to
[golem](https://github.com/golem-mc/golem), the Minecraft: Java Edition server written in Go.

Work in progress.

## Installing

```sh
golem-launcher plugin add github.com/golem-mc/spark
```
